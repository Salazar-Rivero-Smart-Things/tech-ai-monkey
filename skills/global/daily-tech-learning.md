# Daily Software Engineering & Tech Radar (1-Hour Study Procedure)

Stay sharp as a modern software engineer by actively reading, verifying, and distilling the latest developments in technology, developer tooling, frameworks, AI engineering, and tech industry news.

## Supervisor Governance

- **Active Supervisors:** **Gemini** and **DeepSeek** supervise system-level upgrades, architecture decisions, and global knowledge curation.
- Never overwrite core system instructions or publish breaking global changes without clear verification and supervisor oversight.

## Daily Study Workflow

1. **Scan Developer & Tech News (`web_search` + `web_fetch`):**
   - **Software Engineering & Releases:** Official release notes and changelogs for TypeScript, Node.js, Next.js, React, Python, Rust, PostgreSQL, Docker, and local LLM engines (`llama.cpp`, Qwen, Llama, DeepSeek, Gemini).
   - **Developer Communities & Architecture:** Hacker News, Lobsters, GitHub Trending, Pragmatic Engineer, InfoQ, MDN Web Docs.
   - **Tech Magazines & Industry Buzz:** Ars Technica, TechCrunch, The Verge, Wired, MIT Technology Review — capture major industry shifts, security advisories, new products, and notable tech discussions.
2. **Verify Primary Sources:**
   - Open at least 3–5 primary links with `web_fetch` so insights are grounded in actual release notes and engineering posts rather than headlines alone.
3. **Distill Actionable Engineering Takeaways:**
   - Group findings into:
     1. **New Releases & Breaking Changes** (versions, APIs, performance wins)
     2. **Practical Developer Patterns & Tools** (libraries, CLI tools, debugging/testing techniques)
     3. **AI & Local Model Developments** (models, quantization, agents, MCP/tooling)
     4. **Tech Magazine Highlights & Industry Buzz** (notable stories, acquisitions, security alerts)
4. **Persist Durable Knowledge:**
   - Save genuinely reusable technical workflows with `learn_skill` (keep `scope: "personal"` unless explicitly publishing as owner).
   - Store verified version/ecosystem facts with `remember` (and replace stale entries with `forget`).
5. **Output a Clean Daily Digest:**
   - Keep it structured, concise, and packed with clickable source URLs so the user can skim in 2 minutes what you studied during the 1-hour session.
